# Connect Prismical

1. Open the [Prismical app](https://app.prismical.ai) and go to **Settings → API & MCP**.
2. Create an API key for your workspace.
3. Enter it in **Prismical API Key**.

Search and capture use the workspace connected by your API key. Replace the key to switch workspaces, or revoke it in Prismical when no longer needed.

Desktop recording shortcuts use the Prismical app’s current workspace and do not require an API key.
